## S3 终态核对

- 主批次 `runs/s3-A-20261102T094306204655Z` 的 7,040 个结果文件与 manifest 的运行 ID 一一对应。两批补跑分别完成 86 条和 1 条，结果与事件日志归入主批次，派生配置和清单保留在 `runs/s3-T-*`。
- 终止原因分为 2,340 次框架提交、880 次模型主动提交、1,113 次模型超时、423 次工具超时、1 次重试超时和 2,283 次服务错误。服务错误中 2,272 条记录标有 `balance` 计费来源，另有 11 条未记录该字段。
- 8 条宿主环境归档均已有同 ID 的补跑结果。旧分析将两份记录同时计入，得到 4,765 条。11 月 6 日复算优先采用主目录结果，同 ID 的环境归档仅保留作溯源，分析分母为 4,757。
- 当前 `episodes/`、归档的失败尝试、调度标记和 journal 都可在归档中复核。服务错误在本次分析中排除，各臂错误率约为 32.2% 至 32.5%。缺失集中在运行后期，组间比例接近仍可能留下时段与任务构成差异。
