# MXC 白名单启动修复

此前 v3 首条因 CLI 启动失败，原批次保留不修改。经对照验证：在仅系统路径字段的白名单环境中，MXC 无模型本地启动不含 `SystemDrive` 时失败，增加该单个非敏感系统字段后成功。已将 `SYSTEMDRIVE` 加入候选适配器白名单，并新增回归测试。

修复后，使用禁用工具、不包含私有任务的真实 Luna 连通性请求，候选适配器成功返回 submit，并收到 thread.started、turn.started、agent_message 和 turn.completed，直至 EOF 审计完成。13 项适配器与事件离线测试通过。该验证不继承全部环境变量、不执行模型可用命令的隔离探针，也没有重试先前被自动审批拒绝的测试。

本机 `USERPROFILE` 等路径依然可用于 CLI 寻找登录文件，因此此结果不证明独立身份、凭据隔离、网络或整个 Codex 执行链的隔离。仍需独立隔离验证与完整开发集质量检查，不能将这次连接验证视为正式实验。
