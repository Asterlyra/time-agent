# 待验证的任务生成器 v2

这是独立候选版本，未被当前运行的开发批次加载，不属于已冻结测试。入口 `tasks.data_v2.generate(split)` 返回与现有 `tasks.data.generate` 相同的 public/private 结构，需配合 `tasks.data_v2.call_tool` 使用；评分直接复用 `tasks.data.verify`。本版本没有覆盖既有数据文件或运行记录。

候选版本随机化每个实例的文档和表格行 ID、商品名称及行顺序，避免答案证据固定为前三行。证据题含销量合计、链式路线、阈值计数、极差和复合成本，新增两个干扰文档；公开搜索仅返回无数值的摘要，全文需读取。表格题保留 v1 的五种运算及相同连接筛选结构，随机化名称和顺序；其结构多样性仍有限。开发集四种与测试集前四种模板重合、种子不同，第五种只在测试集中出现。

运行 `python -m unittest tests.test_tasks_v2 -v` 可验证确定性、非固定证据 ID 与行位置、筛选证据、无内容搜索摘要和链式检索。正式使用前仍需开发集预跑、独立核算标准答案、审查数据泄漏和任务难度、适配提示和冻结版本；当前并无人工复核。旧版与本版结果不得静默混合。
